# Tanzid Mondol — Portfolio

A modern, responsive portfolio website built with Next.js 15, Tailwind CSS v4, and Framer Motion.

🌐 **Live:** [tanzid-portfolio-ah38.vercel.app](https://tanzid-portfolio-ah38.vercel.app)

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **Font:** Space Grotesk + Inter
- **Contact Form:** Web3Forms
- **Deployment:** Vercel

## Features

- 🌙 Dark / Light mode toggle
- ✨ Smooth scroll animations with Framer Motion
- 📱 Fully responsive — mobile, tablet, desktop
- 🎯 Active section highlight in navbar
- ⌨️ Typing animation in hero section
- 📄 Project detail pages with challenges & future plans
- 📬 Contact form with email notification via Web3Forms
- 🎓 Education timeline — SSC, HSC, University

## Getting Started

```bash
# Clone the repo
git clone https://github.com/tanzid-48/tanzid-portfolio
cd tanzid_portfolio

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your Web3Forms key to .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_WEB3FORMS_KEY=your_web3forms_key_here
```

Get your free key at [web3forms.com](https://web3forms.com)
